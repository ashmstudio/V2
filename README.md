Moving Wallpaper

A simple animated desktop wallpaper created using HTML, CSS, and JavaScript. The wallpaper includes moving and floating visual elements and can be used as an interactive wallpaper through Lively Wallpaper.

Technologies Used

- HTML
- CSS
- JavaScript
- Lively Wallpaper

Features

- Animated moving elements
- Floating visual effects
- Interactive desktop wallpaper
- Designed for use with Lively Wallpaper

Purpose

This project was created to practice using HTML, CSS, and JavaScript to create an animated desktop wallpaper and learn how web technologies can be used for interactive visual projects.
